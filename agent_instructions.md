## 1. Project Purpose

This is an **educational machine learning project** for a B.Pharm student participating in the IBM SkillsBuild AI/ML Internship. The goal is to learn and demonstrate how supervised machine learning can classify health records into diabetic (positive) and non-diabetic (negative) classes using a real Kaggle dataset.

**This is not a medical diagnostic tool.** Do not modify code in a way that presents it as one.

## 3. Dataset Schema

**File:** `data/diabetes_prediction_dataset.csv`  
**Rows:** 100,000 | **Columns:** 9 | **Duplicates:** 3,854

| Column | Python Type | Description |
|---|---|---|
| `gender` | str (object) | "Female", "Male", "Other" |
| `age` | float64 | Age in years (0.08–80) |
| `hypertension` | int64 | 0 or 1 |
| `heart_disease` | int64 | 0 or 1 |

**Class distribution:** 91,500 negative (0), 8,500 positive (1). Imbalanced.

## 6. Model Pipeline

The saved pipeline (`models/best_pipeline.joblib`) uses `sklearn.pipeline.Pipeline` with two named steps:

- `"preprocessor"` — a `ColumnTransformer` with:
  - `"num"` → `StandardScaler` on `["age", "bmi", "HbA1c_level", "blood_glucose_level"]`
  - `"bin"` → passthrough on `["hypertension", "heart_disease"]`
  - `"cat"` → `OneHotEncoder(handle_unknown="ignore")` on `["gender", "smoking_history"]`
- `"classifier"` — the best model (Logistic Regression or Random Forest)

**When generating input for prediction, use this exact column order:**
```python
["gender", "age", "hypertension", "heart_disease",
 "smoking_history", "bmi", "HbA1c_level", "blood_glucose_level"]
```

And these exact data types:
- `gender`: str
- `age`: float
- `hypertension`: int (0 or 1)
- `heart_disease`: int (0 or 1)
- `smoking_history`: str
- `bmi`: float
- `HbA1c_level`: float
- `blood_glucose_level`: int

## 7. Coding Conventions

- Python 3.9+ compatible code only.
- All preprocessing must be inside a `sklearn` `Pipeline` to prevent data leakage.
- Never fit any scaler or encoder on test data.
- All random operations use `random_state=42`.
- Print-based output in `train_model.py` is intentional — it is a terminal training script.
- The dashboard (`app.py`) uses Streamlit only — no Flask, FastAPI, or Django.
- Charts use `matplotlib` with `Agg` backend (`matplotlib.use("Agg")` must appear before import of `pyplot`).
- Avoid third-party packages not listed in `requirements.txt`.

---

## 8. Class Imbalance Handling

The dataset is imbalanced (~91.5% negative, ~8.5% positive).

**Chosen method:** `class_weight="balanced"` in both `LogisticRegression` and `RandomForestClassifier`.

This is preferred over:
- SMOTE (requires an extra package and adds complexity for a beginner project)
- Undersampling (loses data)

Do not change this choice without explaining the tradeoff.

---

## 9. Model Selection Criterion

The best model is selected using **F1-score for the positive class (diabetes = 1)**.

Do **not** use accuracy alone — it is misleading with imbalanced data.

## 13. Common Error Fixes

| Error | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError` | Package not installed | `python -m pip install -r requirements.txt` |
| `FileNotFoundError: diabetes_prediction_dataset.csv` | Dataset not in `data/` | Copy CSV to `data/` folder |
| `Pipeline … not found` | Training not run | Run `python train_model.py` |
| `streamlit: command not found` | PATH issue | Use `python -m streamlit run app.py` |
| `ValueError: could not convert string` | Wrong input dtype | Check that `hypertension` and `heart_disease` are int, not str |
| Slow training | Large dataset | Normal on older hardware — wait 1–3 minutes |
